# MCP Demo

## installation

```bash
# install mcp > 2.x
> pip install "mcp[cli]>2.0"

# install fastapi
> pip install fastapi

# install uvicorn
> pip install uvicorn

# install pymysql
> pip install pymysql

# install pyjwt
> pip install pyjwt

# install mysql mcp server
> pip install mysql-mcp-server

```
