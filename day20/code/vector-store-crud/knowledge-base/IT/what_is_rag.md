# What is RAG?

Retrieval-Augmented Generation (RAG) is a technique that combines:
1. **Retrieval**: Finding relevant information from documents
2. **Generation**: Using AI to create answers based on retrieved info

## How RAG Works:
1. Store documents with vector embeddings
2. Convert user questions to embeddings
3. Find similar documents using vector search
4. Use retrieved context to generate AI response

## Why RAG?
- Uses real, up-to-date information
- Reduces AI hallucinations
- Provides source citations
- Perfect for knowledge-based tasks
