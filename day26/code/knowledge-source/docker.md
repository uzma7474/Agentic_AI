# Docker

Docker is a platform for developing, shipping, and running applications using containers.

## Image

A Docker image is a read-only template used to create containers.

## Container

A container is a running instance of a Docker image.

## Dockerfile

A Dockerfile contains instructions used to build a Docker image.

## Docker Compose

Docker Compose is used to define and run multi-container applications.

A Compose application is typically described using a compose.yaml file.
