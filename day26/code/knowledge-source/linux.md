# Linux

Linux is an open-source operating system kernel used by many operating systems and servers.

## Processes

A process is a running instance of a program.

The ps command can be used to display running processes.

The top command provides a real-time view of system processes.

## Files

The ls command lists files and directories.

The cd command changes the current directory.

The pwd command displays the current working directory.

## Permissions

Linux permissions commonly include read, write, and execute permissions.

Permissions can be changed using the chmod command.
